# الدليل الشامل لتشغيل ونشر وإدارة منصة "خدماتك الرقمية" وتهيئة الـ SEO

دليل مرجعي تفصيلي خطوة بخطوة من الصفر لإعداد وتشغيل منصة **"خدماتك الرقمية"** محلياً وعلى خوادم الإنتاج السحابية، وربطها بالدومين ومحركات البحث Google.

---

## 1. تشغيل المشروع محلياً (Local Setup & Development)

### المتطلبات الأساسية
- تثبيت **Node.js** (الإصدار 18 أو أحدث) على جهازك.

### خطوات التشغيل
1. افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع:
   ```bash
   cd "موقع بيع"
   ```
2. تثبيت الحزم والمكتبات (في حال لم يتم تثبيتها بعد):
   ```bash
   npm install
   ```
3. زراعة البيانات الأولية وحساب الأدمن:
   ```bash
   npm run seed
   ```
4. تشغيل الخادم:
   ```bash
   npm start
   ```
5. افتح المتصفح وتوجه إلى:
   - **الموقع الرئيسي**: `http://localhost:3000`
   - **لوحة تحكم الإدارة**: `http://localhost:3000/admin`
   - **بيانات الدخول الافتراضية**:
     - اسم المستخدم: `admin`
     - كلمة المرور: `admin123456`

---

## 2. إدارة قاعدة البيانات وإعداد الـ Backend

- تعتمد المنصة على قاعدة بيانات **SQLite** سريعة وخفيفة موجودة في المسار:
  `database/khadamatak.db`
- تعمل قاعدة البيانات بنمط **WAL (Write-Ahead Logging)** لضمان سرعة معالجة مئات الطلبات المتزامنة بأمان.
- الهيكل مصمم وفق معايير SQL القياسية، مما يسمح بنقله بسهولة مستقبلاً إلى **PostgreSQL** أو **MySQL** عند الحاجة للتوسع الضخم.

---

## 3. حسابات الإدارة والأمان

- يتم تشفير كافة كلمات المرور باستخدام خوارزمية `bcryptjs` قبل حفظها في قاعدة البيانات.
- يتم تأمين جلسات الإدارة عبر **JWT (JSON Web Token)** مخزن في كوكيز آمنة `HttpOnly` لا يمكن للـ JavaScript في المتصفح قراءتها، مما يحمي من هجمات XSS.
- لتغيير كلمة مرور الأدمن، يمكنك تشغيل استعلام تحديث مشفر أو تغيير متغير البيئة في `.env` وإعادة زراعة البيانات:
  ```env
  ADMIN_PASSWORD=your_new_strong_password
  ```

---

## 4. ربط وتغيير رقم WhatsApp بدون لمس الكود

1. سجل الدخول إلى لوحة التحكم: `/admin`.
2. انتقل إلى تبويب **"إعدادات الموقع" (Settings)** من القائمة الجانبية.
3. اكتب رقم الواتساب الجديد بالصيغة الدولية (مثال: `+962791234567`).
4. اضغط **"حفظ الإعدادات"**.
5. سيتم فورياً تحديث زر الواتساب العائم، وروابط التواصل، والرسائل التلقائية المتولدة عند إرسال الطلبات دون الحاجة لإعادة تشغيل السيرفر أو تعديل أي سطر برمجي.

---

## 5. شراء اسم النطاق (Domain Name)

1. اختر اسماً قصيراً يعبر عن النشاط التجاري (مثال: `khadamatak.com` أو `khadamatak.net`).
2. قم بالشراء عبر مزود نطاقات معتمد مثل:
   - **Namecheap**
   - **Cloudflare Registrar**
   - **GoDaddy**
3. إذا كنت ترغب بنطاق أردني محلي (`.jo` أو `.com.jo`)، يمكنك حجزه من خلال هيئة تنظيم قطاع الاتصالات في الأردن أو المزودين المعتمدين محلياً.

---

## 6. رفع الموقع على الاستضافة السحابية وتفعيل HTTPS

يمكن نشر المشروع بسهولة على أي خادم يدعم Node.js:

### الخيار الأول: النشر السريع على منصات Cloud (مثل Render أو Railway أو VPS)
1. إنشاء حساب على منصة مثل **Render.com** أو **Railway.app**.
2. رفع مجلد المشروع إلى مستودع **GitHub**.
3. إنشاء **Web Service** جديدة وربطها بالمستودع.
4. تحديد أمر البناء: `npm install` وأمر التشغيل: `node server.js`.
5. إضافة متغيرات البيئة من ملف `.env`.
6. توفر هذه المنصات شهادة **SSL (HTTPS)** مجانية وتلقائية بالكامل.

### الخيار الثاني: خادم خاص (Ubuntu VPS) عبر Nginx و PM2
1. تثبيت Node.js و PM2:
   ```bash
   sudo npm install -g pm2
   pm2 start server.js --name "khadamatak"
   pm2 startup
   ```
2. تثبيت وتكوين Nginx كـ Reverse Proxy إلى المنفذ 3000.
3. تفعيل شهادة SSL المجانية عبر Certbot:
   ```bash
   sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
   ```

## 7. تهيئة محركات البحث (Google Search Console & SEO)

1. **إثبات ملكية الموقع**:
   - ادخل إلى [Google Search Console](https://search.google.com/search-console).
   - أدخل رابط موقعك (مثال: `https://yourdomain.com`).
   - اختر طريقة التحقق عبر **DNS TXT Record** وأضف السجل في لوحة الدومين.
2. **إرسال خريطة الموقع (Sitemap)**:
   - الموقع مبرمج لتوليد خريطة موقع ديناميكية محدثة تلقائياً على الرابط:
     `https://yourdomain.com/sitemap.xml`
   - في Search Console، اذهب لقسم **Sitemaps** واكتب `sitemap.xml` ثم اضغط **Submit**.
3. **فحص الروابط وطلب الفهرسة (URL Inspection)**:
   - ادخل رابط أي خدمة جديدة (مثال: `https://yourdomain.com/services/wedding-websites`).
   - اضغط على **"Request Indexing"** لتسريع زحف عناكب قوقل إليها.

## 8. إعداد الملف التجاري في Google Business Profile

إذا كان النشاط يقدم خدماته محلياً:
1. توجه إلى [Google Business Profile](https://business.google.com).
2. أنشئ ملفاً باسم **"خدماتك الرقمية"**.
3. حدد الفئة: *وكالة تصميم مواقع إلكترونية / خدمات برمجية*.
4. أضف رقم الواتساب الرسمي وساعات العمل ورابط الموقع الإلكتروني.
5. أضف صوراً من سابقة الأعمال لزيادة ثقة العملاء والظهور في نتائج الخرائط المحلية في الأردن.

---

## 9. التوسع المستقبلي وربط بوابات الدفع الإلكتروني

تمت هيكلة جدول `payments_log` في قاعدة البيانات ليكون جاهزاً للربط المباشر مع بوابات الدفع الإلكتروني المناسبة للسوق الأردني والعربي:
- **نظام CliQ و المحافظ الإلكترونية** (Zain Cash / Orange Money / UWallet).
- **بوابات البطاقات الائتمانية المحلية والعالمية**: (MEPS, Network International Jordan, HyperPay, Stripe).
- يمكنك ببساطة إنشاء مسار Webhook جديد في `server.js` لاستقبال تأكيد العمليات وتحديث حالة الطلب إلى `مكتمل` تلقائياً.
